# Registro de Mudanças no Código (Changelog) - Versão v3.30.0

## Versão v3.30.0
- **Suporte a Números Decimais no Campo Quantidade**:
  - O campo de input `quantidade` agora aceita valores decimais (ex: `1.5`, `2.75`), permitindo que a entrada numérica seja processada corretamente com ponto decimal junto ao valor unitário.
