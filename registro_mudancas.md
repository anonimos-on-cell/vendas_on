# Registro de Mudanças no Código (Changelog) - Versão v3.3.0

Este documento descreve as alterações e atualizações realizadas no código do sistema **Registradora de Pedidos**.

---

## 1. Atualização para a Versão v3.3.0
- **Inclusão do Botão "Imprimir Recibo de Venda"**:
  - Adicionado botão dedicado no topo do recibo gerado.
  - Criadas regras CSS de impressão (`@media print`) para ocultar o formulário, títulos, botões do recibo e exibir **exclusivamente o Recibo de Venda** na folha/impressora.
