# Registradora de Pedidos - Versão v3.11.0

Sistema completo para registro de pedidos com recibo elegante, organizado em formato de cartão/tabela moderna e QR Code centralizado.

## Como Executar
1. Importe o `banco.sql` no MySQL.
2. Altere os valores no `config.json` conforme sua preferência.
3. Execute `npm install` e `npm start`.
4. Abra o `index.html` no navegador.
