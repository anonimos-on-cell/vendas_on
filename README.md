# Registradora de Pedidos - Versão v2.3.0

Sistema completo para registro de pedidos com opções de pagamento dinâmicas e configurações via arquivos JSON.

## Estrutura
Todos os arquivos do projeto estão organizados dentro do diretório `pedido_v2.3.0`.

## Como Executar
1. Importe o `banco.sql` no MySQL.
2. Altere os valores no `config.json` conforme sua preferência (ex: alterar a chave PIX).
3. Execute `npm install` e `npm start`.
4. Abra o `index.html` no navegador.
