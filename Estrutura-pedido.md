# Árvore da Aplicação - Registradora de Pedidos (v3.31.0)

Esta é a estrutura completa de arquivos da aplicação contida na pasta `pedidos_v3.31.0`:

```text
pedidos_v3.31.0/
│
├── index.html            # Interface principal com Quantidade inteira e Valor Unitário decimal
├── style.css             # Estilização completa com contenção de texto
├── script.js             # Lógica front-end com quantidade inteira e valor unitário decimal
├── server.js             # API Node.js (Express + CORS + MySQL)
├── banco.sql             # Script SQL com quantidade inteira
├── config.json           # Configurações dinâmicas de empresa e Pix

├── registro_mudancas.md  # Histórico detalhado de versões
├── README.md             # Instruções de instalação e uso
```
